# Angel Numbers

A SwiftUI iOS app (iOS 17+) that reveals a random angel number and its meaning, with share and recent history.

## Build
Requires macOS with Xcode 15+.

```sh
brew install xcodegen
xcodegen generate
open AngelNumbers.xcodeproj
```

Pick a simulator and press Run. Set your own bundle ID/team in `project.yml` to run on a device.
